# PassFortress — Password Strength, Brute-Force Visualizer & Digital Hygiene Auditor

An interactive educational platform designed for campus outreach to teach school and rural students how cyber adversaries crack passwords, how to build unbreakable passphrases, and how to fortify personal social media accounts.

---

## 🌟 Key Features

1. **Interactive Credential Entropy Meter**:
   - Calculates real-time information entropy (bits) based on character diversity, length, and common dictionary pattern penalties.
   - Evaluates requirements (length, uppercase, lowercase, numbers, symbols) in real-time.
2. **Adversary Brute-Force Hardware Speed Visualizer**:
   - Compares the time required to crack the user's password across 4 distinct adversary tiers:
     - Standard Laptop CPU (100,000 guesses/sec)
     - High-End GPU Rig / RTX 4090 (10 Billion guesses/sec)
     - Distributed Botnet Cluster (100 Billion guesses/sec)
     - State-Sponsored Supercomputer (10 Trillion guesses/sec)
3. **The "3 Random Words" Passphrase Generator**:
   - Educates students that length beats complexity. Generates easy-to-remember yet mathematically uncrackable passphrases like `Falcon-River-Mango-88!`.
   - 1-click clipboard copy with visual confirmation.
4. **Social Media & Mobile Privacy Audit Checklist**:
   - 10-point actionable security audit covering WhatsApp 2-step verification, Instagram 2FA, UPI scam defense rules, and APK prevention.
   - Live **Personal Cyber Hygiene Score (0 - 100%)** providing direct security guidance.
5. **Bilingual Accessibility (English & Hindi)**:
   - Instant language switch designed specifically for rural outreach settings.

## 🚀 How to Run Locally

1. Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Or use Python's built-in local web server:
   ```bash
   python -m http.server 3001
   ```
   Open `http://localhost:3001` in your browser.
